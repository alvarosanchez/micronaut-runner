Apply the plugin next to the Micronaut plugins your build already applies.

[source.multi-language-sample,groovy,subs="attributes+"]
----
plugins {
    // ... the plugins your build already applies, such as io.micronaut.application
    id 'io.micronaut.runner.standalone' version '{version}'
}
----

[source.multi-language-sample,kotlin,subs="attributes+"]
----
plugins {
    // ... the plugins your build already applies, such as io.micronaut.application
    id("io.micronaut.runner.standalone") version "{version}"
}
----

A project generated by Micronaut Launch also applies the Shadow plugin, `com.gradleup.shadow`, which writes the same
`-all.jar` file. The build fails until only one task writes it. Remove the Shadow plugin, or give the Shadow JARs
another classifier:

[source.multi-language-sample,groovy]
----
tasks.named('shadowJar') {
    archiveClassifier = 'shadow'
}
// Only with Micronaut AOT, whose optimizedJitJarAll task is registered late, so it is matched by name
tasks.named { it == 'optimizedJitJarAll' }.configureEach {
    archiveClassifier = 'shadow-optimized'
}
----

[source.multi-language-sample,kotlin]
----
tasks.named<Jar>("shadowJar") {
    archiveClassifier = "shadow"
}
// Only with Micronaut AOT, whose optimizedJitJarAll task is registered late, so it is matched by name
tasks.withType<Jar>().named { it == "optimizedJitJarAll" }.configureEach {
    archiveClassifier = "shadow-optimized"
}
----

Build and run the Runner JAR:

[source,bash]
----
./gradlew micronautRunnerJar
java -jar build/libs/my-app-0.1-all.jar
----

`micronautRunnerJar` is also part of `assemble`, so `./gradlew build` produces the archive. It takes the main class
from the `application` block and the dependencies from the runtime class path. The archive keeps Shadow's `-all.jar`
name, so Dockerfiles and CI scripts that refer to `+build/libs/*-all.jar+` keep working.

A project that applies Micronaut AOT also gets `optimizedMicronautRunnerJar`, which packages the optimized
application as `-all-optimized.jar` (<<micronautAot,Micronaut AOT>>).

Everything else stays the same: `./gradlew run` and the tests do not use the Runner JAR. Neither do Micronaut's
`dockerBuild` and `dockerfile` tasks; to ship the Runner JAR in an image, see <<quickStartContainer,Running in a Container>>.

To go back to Shadow, remove the plugin, and restore the Shadow plugin or its classifier.
