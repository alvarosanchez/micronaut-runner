These system properties are read when the application starts, so pass them on the `java` command line, before
`-jar`. They are not packaging options.

To look into a start or an archive:

[cols="3,1,5",options="header"]
|===
|Property |Default |Use it to

|`micronaut.runner.mode`
|`run`
|Look into the archive instead of starting it: `inspect` prints a summary (<<quickStartCheck,Checking the Archive>>),
`list` prints the entries, optionally only those under a prefix given as an argument, and `extract` writes a
directory (<<extract,Extracting to a Directory>>).

|`micronaut.runner.timing`
|`false`
|With `true`, print when the launcher opened the archive, read the index, made the class loader ready and entered
your application, and when preloading finished. Use it to tell launcher time from framework time.

|`micronaut.runner.verify`
|`false`
|With `true`, check every entry's checksum as it is read, when you suspect a corrupted archive.

|`micronaut.runner.static-services.verify`
|`false`
|With `true`, compare the precomputed service lookups with Micronaut's own scan
(<<staticServices,Precomputed Service Lookups>>).
|===

To change how the application starts:

[cols="3,1,5",options="header"]
|===
|Property |Default |Use it to

|`micronaut.runner.preload`
|`true`
|With `false`, start without preloading the <<startupProfile,startup profile>>.

|`micronaut.runner.mmap`
|from the archive
|Choose how the archive is read: `full` maps it whole, `index` maps only the index
(<<archiveReads,Mapped or Positional Reads>>), and `false` maps nothing, for a platform where mapping files is not
wanted. Unset, the archive's `archiveReads` option decides.

|`micronaut.runner.parent`
|`platform`
|With `system`, let an agent or tool on the real class path share types with the application
(<<javaAgents,Java agents>>). It also turns off the precomputed service lookups.

|`micronaut.logback.precompiled`
|`true`
|With `false`, configure Logback from `logback.xml` with Joran instead of the precompiled configuration. It is
Micronaut AOT's switch, and works in every packaging (<<precompiledLogback,Precompiled Logback Configuration>>).

|`micronaut.runner.static-services`
|`true`
|With `false`, let Micronaut scan for its services instead of using the precomputed lookups.

|`micronaut.runner.prefetch`
|`true`, when packaged with `definitionPrefetch`
|With `false`, start without the <<definitionPrefetch,bean definition prefetch>>.
|===

Write `true` and `false` in lower case: most switches do not recognise `FALSE` or `True`.

Several packaging options have a switch that overrides them for one start:

[cols="1,1",options="header"]
|===
|Packaging option |Run-time switch

|`archiveReads` (`MAPPED`, `POSITIONAL`) |`micronaut.runner.mmap` (`full`, `index`)
|`precompileLogback` |`micronaut.logback.precompiled`
|`staticServices` |`micronaut.runner.static-services`
|`definitionPrefetch` |`micronaut.runner.prefetch`
|`startupClasses`, or a committed startup profile |`micronaut.runner.preload`
|===

A switch can turn a packaged feature off, but cannot add one that was not packaged.
