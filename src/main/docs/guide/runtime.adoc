A Runner JAR is an ordinary executable JAR:

[source,bash]
----
java -jar build/libs/my-app-0.1-all.jar
----

Arguments after the JAR reach your application unchanged. An exception your application throws propagates as it
would from any main class, and the exit status is the JVM's own. The launcher chooses the `main` method as the `java`
launcher does, including the instance `main` methods of recent Java versions.
